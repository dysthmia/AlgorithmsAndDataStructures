# Модульная арифметика — C++

**Модульная арифметика** — операции над числами с использованием остатка от деления на заданный модуль.

В примерах используется `mod = 11`.

## 1. Реализация

Поддерживаются следующие операции:

- `modsum(a, b)` — сложение по модулю.
- `modsub(a, b)` — вычитание по модулю.
- `modmul(a, b)` — умножение по модулю.
- `modpow(a, n)` — возведение в степень по модулю.
- `moddiv(a, b)` — деление по модулю.

```cpp
#include <iostream>
#include <cstdint>
using namespace std;

const int mod = 11;

// Сложение по модулю
int64_t modsum(int64_t a, int64_t b) {
    int64_t s = ((a % mod + b % mod) % mod + mod) % mod;
    return s;
}

// Вычитание по модулю
int64_t modsub(int64_t a, int64_t b) {
    int64_t s = ((a % mod - b % mod) % mod + mod) % mod;
    return s;
}

// Умножение по модулю
int64_t modmul(int64_t a, int64_t b) {
    int64_t s = (a * b % mod + mod) % mod;
    return s;
}

// Возведение в степень по модулю
int64_t modpow(int64_t a, int64_t n) {
    if (n == 0) return 1;

    if (n % 2 == 0) {
        return modpow(a * a % mod, n / 2);
    }

    return a * modpow(a, n - 1) % mod;
}

// Деление по модулю (теорема Ферма)
int64_t moddiv(int64_t a, int64_t b) {
    a = (a % mod + mod) % mod;
    b = (b % mod + mod) % mod;

    int64_t s = a * modpow(b, mod - 2) % mod;
    return s;
}

int main() {
    return 0;
}
```

## 2. Основные операции

### Сложение по модулю

$$
(a+b)\bmod m
$$

Пример:

$$
(8+7)\bmod 11=4
$$

### Вычитание по модулю

$$
(a-b)\bmod m
$$

Чтобы избежать отрицательного остатка:

$$
((a-b)\bmod m+m)\bmod m
$$

Пример:

$$
(3-8)\bmod 11=6
$$

### Умножение по модулю

$$
(a\cdot b)\bmod m
$$

Пример:

$$
(7\cdot 8)\bmod 11=1
$$

### Возведение в степень по модулю

$$
a^n\bmod m
$$

Используется **быстрое возведение в степень**.

Если степень чётная:

$$
a^n=(a^2)^{n/2}
$$

Если степень нечётная:

$$
a^n=a\cdot a^{n-1}
$$

**Сложность:** `O(log n)`.

## 3. Деление по модулю — малая теорема Ферма

Обычное деление по модулю заменяется умножением на обратный элемент.

$$
\frac{a}{b}\equiv a\cdot b^{-1}\pmod p
$$

### Малая теорема Ферма

Если `p` — простое число и `a` не делится на `p`, то:

$$
a^{p-1}\equiv1\pmod p
$$

Представим степень в виде произведения:

$$
a\cdot a^{p-2}\equiv1\pmod p
$$

Следовательно:

$$
\boxed{a^{-1}\equiv a^{p-2}\pmod p}
$$

Отсюда формула деления:

$$
\boxed{\frac{a}{b}\equiv a\cdot b^{p-2}\pmod p}
$$

### Пример

Вычислим:

$$
\frac{8}{3}\pmod{11}
$$

Найдём обратный элемент к `3`:

$$
3^{-1}\equiv3^9\equiv4\pmod{11}
$$

Умножаем:

$$
8\cdot4\bmod11=10
$$

**Ответ: 10.**

### Важные условия

- Модуль `p` должен быть простым для применения формулы Ферма.
- Делитель `b` не должен делиться на `p`.
- Для составного модуля обратный элемент можно искать расширенным алгоритмом Евклида, если он существует.
- `modpow` рассчитан на неотрицательные степени.
- Для очень больших чисел при умножении возможен выход за пределы `int64_t`.

## 4. Сложность операций

| Операция | Сложность |
|---|---|
| `modsum(a, b)` | `O(1)` |
| `modsub(a, b)` | `O(1)` |
| `modmul(a, b)` | `O(1)` |
| `modpow(a, n)` | `O(log n)` |
| `moddiv(a, b)` | `O(log mod)` |

Оценки приведены для арифметики фиксированной разрядности.

## 5. Главное, что нужно запомнить

**Малая теорема Ферма:**

$$
a^{p-1}\equiv1\pmod p
$$

**Обратный элемент:**

$$
a^{-1}\equiv a^{p-2}\pmod p
$$

**Деление по модулю:**

$$
\boxed{\frac{a}{b}\equiv a\cdot b^{p-2}\pmod p}
$$

Все три формулы требуют простого модуля `p` и ненулевого по модулю соответствующего основания или делителя.
