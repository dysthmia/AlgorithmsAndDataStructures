# Бор (Trie) — C++

**Бор (Trie)** — дерево для хранения строк, в котором каждое ребро соответствует символу.

Бор позволяет:
- Добавлять и искать строки.
- Подсчитывать количество слов с заданным префиксом.
- Находить кратчайший уникальный префикс.
- Подсчитывать количество вершин.

Во всех примерах используется `std::map<char, Node>` для хранения переходов между вершинами.

---

## 1. Базовая реализация бора

Поддерживает две операции:

- `insert(s)` — добавить строку в бор.
- `find(s)` — проверить, существует ли строка в боре.

```cpp
#include <iostream>
#include <map>
#include <string>

struct Node {
    std::map<char, Node> next;
    bool is_terminal = false;
} root;

void insert(const std::string& s) {
    Node* v = &root;

    for (const auto ch : s) {
        v = &v->next[ch];
    }

    v->is_terminal = true;
}

bool find(const std::string& s) {
    Node* v = &root;

    for (const auto ch : s) {
        auto it = v->next.find(ch);

        if (it == v->next.end()) {
            return false;
        }

        v = &it->second;
    }

    return v->is_terminal;
}

int main() {
    insert("aaa");
    insert("bbb");
    insert("aba");

    std::cout << find("bbb") << '\n';

    return 0;
}
```

**Результат:**

```text
1
```

`is_terminal` показывает, заканчивается ли в данной вершине добавленное слово.

## 2. A4 — Сколько слов с данным префиксом?

Для каждой вершины храним `count` — количество добавленных слов, проходящих через эту вершину.

При добавлении слова увеличиваем `count` у всех вершин на его пути, включая корень.

```cpp
#include <iostream>
#include <map>
#include <string>

struct Node {
    std::map<char, Node> next;
    int count = 0;
} root;

void insert(const std::string& s) {
    Node* v = &root;
    ++v->count;

    for (const auto ch : s) {
        v = &v->next[ch];
        ++v->count;
    }
}

int find(const std::string& s) {
    Node* v = &root;

    for (const auto ch : s) {
        auto it = v->next.find(ch);

        if (it == v->next.end()) {
            return 0;
        }

        v = &it->second;
    }

    return v->count;
}

int main() {
    int n, m;
    std::cin >> n;

    for (int i = 0; i < n; i++) {
        std::string s;
        std::cin >> s;
        insert(s);
    }

    std::cin >> m;

    for (int i = 0; i < m; i++) {
        std::string s;
        std::cin >> s;
        std::cout << find(s) << '\n';
    }

    return 0;
}
```

**Пример ввода:**

```text
4
apple
app
apply
banana
3
app
ban
cat
```

**Вывод:**

```text
3
1
0
```

Префикс `app` встречается у трёх слов: `apple`, `app`, `apply`.

## 3. B4 — Кратчайший уникальный префикс строки

Нужно найти самый короткий префикс, который встречается только у одного слова из всех добавленных.

Используем `count` из предыдущей задачи.

Как только попадаем в вершину с `count == 1`, найден уникальный префикс.

```cpp
#include <iostream>
#include <map>
#include <string>
#include <vector>

struct Node {
    std::map<char, Node> next;
    int count = 0;
} root;

void insert(const std::string& s) {
    Node* v = &root;
    ++v->count;

    for (const auto ch : s) {
        v = &v->next[ch];
        ++v->count;
    }
}

std::string find(const std::string& s) {
    Node* v = &root;
    std::string res;

    for (const auto ch : s) {
        auto it = v->next.find(ch);

        if (it == v->next.end()) {
            return "-";
        }

        v = &it->second;
        res.push_back(ch);

        if (v->count == 1) {
            return res;
        }
    }

    return "-";
}

int main() {
    int n;
    std::cin >> n;

    std::vector<std::string> words(n);

    for (auto& s : words) {
        std::cin >> s;
        insert(s);
    }

    for (const auto& s : words) {
        std::cout << find(s) << '\n';
    }

    return 0;
}
```

**Пример ввода:**

```text
4
apple
apply
banana
cat
```

**Вывод:**

```text
appl e
appl y
b
c
```

Здесь пробелы в первых двух строках нужны только для наглядности. Фактический вывод программы:

```text
apple
apply
b
c
```

**Примечание:** если ни у одного префикса строки `count` не равен `1`, функция возвращает `"-"`. Например, такое возможно для одинаковых слов или когда одно слово является префиксом другого.

## 4. C4 — Количество вершин в боре

Нужно подсчитать количество вершин, созданных после добавления всех строк.

Изначально существует одна вершина — корень.

Новая вершина появляется только тогда, когда нужного перехода ещё нет.

```cpp
#include <iostream>
#include <map>
#include <string>

struct Node {
    std::map<char, Node> next;
} root;

int count = 1;

void insert(const std::string& s) {
    Node* v = &root;

    for (const auto ch : s) {
        if (v->next.find(ch) == v->next.end()) {
            ++count;
        }

        v = &v->next[ch];
    }
}

int main() {
    int n;
    std::cin >> n;

    for (int i = 0; i < n; i++) {
        std::string s;
        std::cin >> s;
        insert(s);
    }

    std::cout << count << '\n';

    return 0;
}
```

**Пример ввода:**

```text
3
aaa
aba
abb
```

**Вывод:**

```text
7
```

В боре 7 вершин, включая корень.

Повторное добавление одинаковых строк не создаёт новые вершины.

## 5. Универсальная структура данных Trie

Более удобная реализация, в которой все операции объединены в одной структуре.

```cpp
#include <iostream>
#include <map>
#include <string>

struct Trie {
    struct Node {
        std::map<char, Node> next;
        bool is_terminal = false;
    };

    Node root;

    // Добавление строки
    void insert(const std::string& s) {
        Node* v = &root;

        for (char ch : s) {
            v = &v->next[ch];
        }

        v->is_terminal = true;
    }

    // Поиск строки
    bool find(const std::string& s) const {
        const Node* v = &root;

        for (char ch : s) {
            auto it = v->next.find(ch);

            if (it == v->next.end()) {
                return false;
            }

            v = &it->second;
        }

        return v->is_terminal;
    }

    // Проверка префикса
    bool starts_with(const std::string& s) const {
        const Node* v = &root;

        for (char ch : s) {
            auto it = v->next.find(ch);

            if (it == v->next.end()) {
                return false;
            }

            v = &it->second;
        }

        return true;
    }
};

int main() {
    Trie trie;

    trie.insert("aaa");
    trie.insert("bbb");
    trie.insert("aba");

    std::cout << trie.find("bbb") << '\n';
    std::cout << trie.find("abb") << '\n';
    std::cout << trie.starts_with("ab") << '\n';

    return 0;
}
```

**Вывод:**

```text
1
0
1
```

### Методы

| Метод | Описание |
|---|---|
| `insert(s)` | Добавить строку |
| `find(s)` | Проверить существование строки |
| `starts_with(s)` | Проверить существование префикса |

## 6. Сложность операций

Пусть:

- `L` — длина строки.
- `K` — количество различных символов алфавита.

Так как переходы хранятся в `std::map`, поиск перехода занимает `O(log K)`.

| Операция | Сложность |
|---|---|
| Вставка строки | `O(L log K)` |
| Поиск строки | `O(L log K)` |
| Количество слов с префиксом | `O(L log K)` |
| Кратчайший уникальный префикс | `O(L log K)` |
| Подсчёт вершин при вставке | `O(L log K)` |

Для фиксированного небольшого алфавита эти операции работают за `O(L)`.

**Память:** `O(S)`, где `S` — суммарная длина всех добавленных строк. Общие префиксы хранятся только один раз.
