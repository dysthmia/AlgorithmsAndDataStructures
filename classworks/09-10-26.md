## Что такое префикс
Строка `Р` называется **префиксом** строки `L` в случае если существует строка `Х` для которой выполняется равенство `L = P + X` (`P + X` — обозначает конкатенацию строк P и Х). Равноценным определением будет: префикс (P) - подстрока L с начальным индексом равным 0.
Префикс называется собственным в случае если Х — не пустая строка или длина префикса не
равна длине строки.

## Таблица префиксов
**Таблица префиксов** строки `L` определяется следующим образом. Для каждого индекса строки вычисляется длина максимального общего префикса подстроки начинающейся с этого индекса и базовой строки L. Если принять нумерацию символов с нуля, то pr[i] — длина самого большого префикса L начинающегося с позиции і. По определению pr[O] = [L]
``` text
Нам нужно выяснить, насколько начало строки похоже на каждую её позицию.

Например:
s = "a b a c a b a"
z = [0,0,0,0,0,0,0]

1) берем i = 1:
    s   = "a"       +   "b a c a b a"
    s'  = "b a c a b a"
    ни одного символа не совпадает => z[i] = z[1] = 0

2) берем i = 2:
    s   = "a b"     +   "a c a b a"
    s'  = "a c a b a"
    совпал 1 символ 'a' => z[i] = z[2] = 1

3) берем i = 3:
    s   = "a b a"   +   "c a b a"
    s'  = "c a b a" 
    ни одного символа не совпадает => z[i] = z[3] = 0

4) берем i = 4:
    s   = "a b a c"   +   "a b a"
    s'  = "a b a"
    совпало 3 символа  => z[i] = z[4] = 3

5) берем i = 5:
    s   = "a b a c a"   +   "b a"
    s'  = "b a"
    ни одного символа не совпадает => z[i] = z[5] = 0

.....

z = [0 0 1 0 3 0 1]
```


### Простейший алгоритм O(n^2)

1. Перебираем каждую позицию i, кроме нулевой.
2. Сравниваем символы s[0] и s[i].
3. Если они равны — увеличиваем длину совпадения.
4. Сравниваем следующие символы.
5. Останавливаемся, когда символы различаются или закончилась строка.

``` c++
#include <iostream>
#include <string>
#include <vector>

using namespace std;

vector<int> z_func (string s, size_t n) {
    vector<int> z (n, 0);
    for (size_t i=1; i<n; i++) {
        while (i + z[i] < n && s[z[i]] == s[i+z[i]]) {
            z[i]++;
        }
    }
    return z;
}

int main () {
    string s; cin >> s;
    vector<int> z = z_func(s, s.length());
    for (int i : z) cout << i << ' ';
    return 0;
}
```

### Алгоритм за O(n)

``` c++
#include <iostream>
#include <string>
#include <vector>

using namespace std;

vector<int> z_func(string s, size_t n) {
    vector<int> z(n, 0);
    size_t l = 0, r = 0;
    for (size_t i=1; i<n; i++) {
        if (i<=r) z[i] = z[i - l];
        while (i+z[i]<n && s[z[i]] == s[i + z[i]]){
            z[i]++;
        }
        if (i + z[i] - 1 > r) {
            r = i + z[i] - 1;
            l = i;
        }
    }
    return z;
}

int main () {
    string s; cin >> s;
    vector<int> z = z_func(s, s.length());
    for (int i : z) cout << i << ' ';
    return 0;
    return 0;
}
```
