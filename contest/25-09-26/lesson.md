# ПРЯМОЙ и ОБРАТНЫЙ полиномиальный хэш

$$  hash = ∑ (Si * P^(i))%m $$

## Прямой

Число: 173 

его прямой полиномиальный хэш выглядит вот так:

173 = 1 * 10^2 + 7* 10^1 + 3* 10^0

173 = ((0*10 + 1)*10 + 7)*10 + 3 


``` cpp
int p, m;

string s; // 173 
int len = s.length();

int hash = 0;

for (int i=len-1; i>=0; i--) // ! важно
// чтобы получить формулу 1 * 10^2 + 7* 10^1 + 3* 10^0 
// мы должны начинать с конца тоесть у 3 была 
// наименьшая степень тоесть 0
{
    hash = (h * p + (s[i]- 'a' + 1)) % m;
}
```

## Обратный

Число: 173 

его обратный полиномиальный хэш выглядит вот так:

1 * 10^0 + 7* 10^1 + 3 * 10^2 

((0*10 + 3)*10 + 7)*10 + 1


``` cpp
int p, m;

string s; 
int len = s.length();

int hash = 0;

for (int i=0; i<len; i++) // ! тут наоборот
// должна быть формула 1 * 10^0 + 7* 10^1 + 3 * 10^2
// тоесть мы как бы идем в обратном направлении
// чтобы у тройки была наибольшая степень
{
    hash = (h * p + (s[i]- 'a' + 1)) % m;
}
```
